# ⚽ Fantasy Premier League Squad Helper

This Python script helps Fantasy Premier League (FPL) managers analyze their current squad and get replacement suggestions based on injuries or poor form.

---

## 📌 Features

- ✅ Fetches the current gameweek squad of a user using their FPL ID.
- ✅ Lists players in the squad with their status and injury news.
- ✅ Detects the most expensive **injured** player or the **lowest form** player.
- ✅ Suggests a **replacement player** within the same position and budget who is fit and in good form.

---

## 🛠 Prerequisites

1. **Python**: Ensure you install Python (preferably Python 3.8 or later).
2. **Libraries**: Install the following Python libraries:
   - `requests`: Allows you to send HTTP requests
